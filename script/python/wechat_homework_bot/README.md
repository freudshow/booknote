# 微信群作业自动下载工具

自动监听指定微信群，在设定时间窗口内（默认 15:00-20:00），将指定发布者发送的作业相关消息（文本、图片、视频、语音、文档、链接、笔记）按 **日期/学科/文件类型** 自动归类保存到本地目录。

## 功能特性

- ⏰ **定时运行**：可配置时间窗口（默认 15:00-20:00），窗口外不消耗资源
- 👥 **多群监听**：同时监听多个微信群
- 🎯 **发布者过滤**：仅保存指定发布者（老师/班主任）的消息，忽略家长闲聊
- 📚 **智能分学科**：按关键词自动判断学科（语文/数学/英语/古筝/体育等）
- 📁 **分类存储**：自动按 `群名/日期/学科/文件类型/` 目录结构保存
- 🔄 **多格式支持**：文本、图片、视频、语音、文件、链接、笔记
- 🎤 **语音转文字**：可选启用语音自动转文字（需额外依赖）
- 📝 **笔记完整保存**：笔记中的图片/文件/视频自动提取，内容转 Markdown
- 🛡 **去重机制**：基于消息 hash 去重，避免重复保存

## 安装要求

- Windows 10/11
- Python 3.8+
- 微信 PC 版（已登录，保持在线）
- 管理员权限（wxauto 需要 UI 自动化权限）

## 快速开始

### 1. 克隆/下载项目
```cmd
# 假设放在 C:\Users\floyd\wechat_homework_bot
```

### 2. 安装依赖
```cmd
cd C:\Users\floyd\wechat_homework_bot
pip install -r requirements.txt
```

### 3. 修改配置
编辑 `config.yaml`：
- `save_root`：保存根目录（默认 `C:/Users/%USERNAME%/Documents/WeChat_Homework`）
- `groups`：确认群名完全一致（含 emoji）
- `publishers`：每个群的作业发布者群昵称/备注
- `subject_keywords`：按需调整学科关键词
- `schedule`：调整监听时间窗口

### 4. 运行
**方式一：双击运行**
- 双击 `run.bat`

**方式二：命令行运行**
```cmd
python main.py
```

**方式三：后台服务（可选）**
使用 NSSM 或 Windows 任务计划程序设置开机自启。

## 配置说明 (config.yaml)

| 配置项 | 说明 |
|--------|------|
| `schedule.start_hour/end_hour` | 监听时间窗口（24小时制） |
| `schedule.poll_interval_seconds` | 时间窗口内轮询间隔（秒） |
| `save_root` | 文件保存根目录（支持 `%USERNAME%` 等环境变量） |
| `groups[].name` | 微信群名称（必须完全一致，含 emoji） |
| `groups[].publishers` | 该群的作业发布者列表（群昵称/备注），空=不限制 |
| `groups[].subject_keywords` | 学科关键词映射，用于自动分类 |
| `file_type_dirs` | 消息类型到目录名的映射 |
| `voice_to_text.enabled` | 是否启用语音转文字（需额外模型） |
| `logging` | 日志配置 |

## 常见问题

### Q: 微信群名带 emoji 怎么填？
A: 直接复制粘贴群名到配置文件（YAML 支持 Unicode），如 `🎖️星海一年二班家长成长同盟群`

### Q: 怎么获取发布者的准确群昵称？
A: 在微信群右侧成员列表查看，或运行脚本后查看日志中的 `发送者` 字段

### Q: 文件下载失败怎么办？
A: 
- 确保微信窗口未最小化、未被遮挡
- 文件过期/未下载需手动点击一次，脚本会自动触发下载
- 大文件/视频需增加 `timeout`（配置中暂不暴露，可改代码）

### Q: 语音转文字不工作？
A: 需安装 `funasr` 等模型，较大（~1GB），建议不启用或使用在线 API

### Q: 怎么添加新群/新学科？
A: 直接在 `config.yaml` 的 `groups` 数组中追加，重启脚本生效

### Q: 能否在服务器/无界面环境运行？
A: **不能**。wxauto 基于 UI 自动化，需要桌面会话、微信窗口可见。如需无头运行，请研究 WeChatFerry (wcferry) + 特定版本微信 + DLL 注入方案。

## 注意事项

1. **微信版本**：建议使用微信 3.9.x 稳定版，过新版本可能导致 UI 自动化失效
2. **防打扰**：监听群建议设置"消息免打扰"，避免弹窗干扰自动化
3. **磁盘空间**：视频/图片较大，定期清理或挂载大盘
4. **杀毒软件**：可能拦截 UI 自�动化操作，需加白名单
5. **单实例**：同一微信账号同一时间只能运行一个实例

## 卸载/清理

删除项目文件夹即可，不修改系统注册表、不安装驱动。
