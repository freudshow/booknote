在仓库根目录执行下面的命令，可以把**已跟踪且相对 `HEAD` 有修改、但尚未提交的文件**，按原来的相对目录结构复制到另一个目录：

```bash
rsync -a \
  --from0 \
  --files-from=<(git diff --name-only --diff-filter=ACMRTUXB -z HEAD --) \
  --relative \
  ./ \
  /path/to/目标目录/
```

```bash

  --relative \
  ./ \
  ../backup/
```

如果仓库中有：

```text
src/main.c
config/app.yaml
README.md
```

复制后会得到：

```text
../backup/src/main.c
../backup/config/app.yaml
../backup/README.md
```

这里使用 `git diff HEAD`，因此会同时包含：

- 工作区中修改但未暂存的文件
- 已暂存但未提交的文件

如果还要包括**未被 Git 跟踪的新文件**，可以使用这个 Python 脚本，能正确处理文件名中的空格和中文：

```python
from pathlib import Path
import shutil
import subprocess

repo = Path(".").resolve()
target = Path("../backup").resolve()

tracked = subprocess.check_output(
    ["git", "diff", "--name-only", "--diff-filter=ACMRTUXB", "HEAD", "--"],
    text=True,
).splitlines()

untracked = subprocess.check_output(
    ["git", "ls-files", "--others", "--exclude-standard"],
    text=True,
).splitlines()

files = set(tracked + untracked)

for name in files:
    source = repo / name
    destination = target / name

    if source.is_file():
        destination.parent.mkdir(parents=True, exist_ok=True)
        shutil.copy2(source, destination)
        print(f"{source} -> {destination}")
```

将脚本放在仓库根目录运行即可。它会复制：

- 已修改的已跟踪文件
- 已暂存的文件
- 未跟踪但未被 `.gitignore` 忽略的新文件

已删除的文件不会被复制。
