`SYS_gettid` 是 Linux 头文件 `<sys/syscall.h>` 中定义的**系统调用编号**，对应 `gettid` 系统调用。调用它会取得**当前线程的 TID（线程 ID）**；多线程进程里的各线程共享同一个 PID，但每个线程有自己的 TID。[1,2]

```c
#include <sys/syscall.h>
#include <unistd.h>

long tid = syscall(SYS_gettid);
```

如果使用支持 `gettid()` 的较新 GNU C 库，也可以直接调用 `gettid()`。它返回的 TID 和 `pthread_self()` 返回的 POSIX 线程标识不是同一种值。[1]

两者都表示**当前线程**，但代表的是不同层面的线程标识，不能当作同一种 ID 使用：

| 接口 | 返回类型 | 标识用途 |
|---|---|---|
| `pthread_self()` | `pthread_t` | POSIX 线程库的线程标识；用于 `pthread_equal()`、`pthread_join()` 等 pthread 接口。它是不透明类型，不能假定是整数，也不应直接用 `==` 比较。[1] |
| `syscall(SYS_gettid)` | `long`（系统调用结果；`gettid()` 包装函数返回 `pid_t`） | Linux 内核的线程 ID（TID）；常用于日志、`/proc` 或 Linux 特有的系统调用。多线程进程中，各线程共享 PID，但 TID 不同。[2] |

它们通常**数值不同**，即使是在同一个线程中取得的值；不要把 `pthread_self()` 的结果强转成 TID，也不要用 `pthread_t` 去调用需要内核 TID 的接口。手头要操作 POSIX 线程就用 `pthread_t`；需要 Linux 内核 TID 就用 `gettid()` 或 `syscall(SYS_gettid)`。[1,2]

```c
pthread_t pt = pthread_self();   // POSIX 线程标识
long tid = syscall(SYS_gettid);  // Linux 内核 TID
```

比较两个 `pthread_t` 时用 `pthread_equal(a, b)`，不要直接用 `a == b`。
